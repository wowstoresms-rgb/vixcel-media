======================================================================
VIXCEL MEDIA — دليل التشغيل والنشر وتحويل التطبيق إلى APK
======================================================================

محتويات مجلد (vixcel_media):
1. index.html    -> التطبيق الكامل (واجهة أدوات المستندات + تحميل الفيديو + تحويل الصيغ + النقل السريع + الصوت العربي والإنجليزي + الإعلانات والنقاط).
2. admin.html    -> لوحة تحكم الأدمن المرئية لتغيير أي نص أو أيقونة أو لون أو كود إعلان أو إرسال رسالة للمستخدمين.
3. config.json   -> ملف الإعدادات المركزي للتحديثات الفورية عن بُعد.
4. manifest.json & sw.js -> ملفات تشغيل التطبيق كتطبيق موبايل (PWA / APK).

طريقة النشر المجاني وتحويله إلى APK:
1. ارفع مجلد (vixcel_media) مجاناً على Netlify Drop أو GitHub Pages.
2. لتحويله إلى ملف أندرويد (.apk): ضع رابط موقعك في موقع PWABuilder.com وحمّل الـ APK جاهزاً.
3. لإرسال تحديث أو رسالة لكل المستخدمين: افتح (admin.html) من المتصفح، عدّل ما تريد واضغط (تحميل ملف config.json)، ثم استبدل ملف config.json في الاستضافة وسيظهر التحديث عند كل المستخدمين فوراً!
